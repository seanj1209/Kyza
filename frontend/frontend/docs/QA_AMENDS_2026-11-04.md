# QA/DEV amendments — 4 November 2026

Source: `KYZA UPDATES_AMENDS V1.0#.pdf`, pages 1–2. Its page 3 contains an empty item 6, so there is no sixth implementation item.

## Changes for QA review

- Strip Laminate pre-slit preview shows 50% red clear-strip off-cuts with vertical `PIFA 3 "OFF-CUT"` text. Remaining substrate lanes use the selected substrate colour at 80%. The repeat width and overall height callouts are hidden; step and segment widths remain. PDF and Illustrator-compatible SVG retain the selected view. JSON records `cutterSpecification.viewMode` alongside the unchanged construction data.
- 2-side and 3-side seal pouches, and the 3-side seal sachet, default to a 0.4 mm cutter stroke. An explicit user stroke remains editable. The 4-side sachet default is unchanged.
- The colour options panel stays open after choosing multiple swatches, including selected BBE/barcode/QR object colours. Clicking outside closes it.
- JSON export passes `application/json` to the native save picker, while the file Blob retains its UTF-8 content type.
- Pillow width or seal changes rederive the two construction folds from the working width. A safe zone previously fitted to a panel follows the resized panel. Manual safe-zone dimensions remain manual.
