# Kyza Visual Direction Brief

## Purpose
Define the visual style, theme and user experience direction for Kyza before applying changes to the MVP.

## Goal
Find a base UI direction that can be used consistently across:
- Dashboard
- Pack Generator
- Cutter Studio
- Artwork Studio
- Projects
- Exports
- Account/Billing

## Design Intent
Kyza should feel like a professional packaging CAD/SaaS platform, not a chatbot or basic form app.

## Visual Keywords
- professional
- technical
- clean
- production-focused
- premium
- precise
- structured
- modern
- editor-like
- workflow-driven

## Preferred Layout Feel
- left navigation
- top project/status bar
- central canvas or preview area
- right-side tools/properties panel
- bottom validation/status strip
- stage/progress indicator between Pack Gen, Cutter and Artwork

## Core Stages
1. Pack Generator — guided setup and generation
2. Cutter Studio — precision editing and production tools
3. Artwork Studio — preflight, overlay and approval checks

## Design Must Avoid
- chatbot-first layout
- playful/childish colours
- generic website feel
- too much white space
- disconnected page styles
- random styling between modules
- hiding validation/warnings

## Prototype Rule
Google AI Studio App Builder should only create visual/UI prototypes using mock data.
It must not build real engine logic.
It must not replace the current MVP shell yet.
